# Adu Birthday — Complete Optimized Package

This package contains the complete website and its optimized media.

## Included
- index.html
- style.css
- script.js
- README.md
- assets/bgm/birthday-bgm.mp3
- assets/photos/01.webp–10.webp — 10 solo Adu photos for Love Archive
- assets/photos/11.webp–30.webp — 20 couple photos for Our Little Museum / Gallery

The photos were resized and converted to WebP so the website loads faster and the ZIP is much smaller, while retaining the original photo content.

## Run
Extract the ZIP and open `index.html`, or upload the extracted folder to your web host/GitHub Pages.
